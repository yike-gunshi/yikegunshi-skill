# 即梦操作：让橘猫的头绕一圈

这是整个流程里唯一要你亲手做的一步。AI 不能替你登录即梦，也不会假装已经生成过视频。

要用的图：`../output/3D头像-选中.png`（AI 已经出好、选好的那张 3D 橘猫）

## 1. 去哪做、怎么设置

1. 打开即梦 → **视频生成** → 选 **首尾帧** 模式
2. 首帧、尾帧**都上传同一张** `3D头像-选中.png`。视频从正脸开始、回到正脸结束，头正好转一圈闭合
3. 时长选 **5 秒**；动作看着太赶，再试 **10 秒**
4. 比例跟随图片（16:9 横版）
5. 同一个提示词**生成 3–4 条**，从里面挑最好的一条

## 2. 提示词

先用主版。主版的几条都走不圆，再换备选 B；转得忽快忽慢、漏了某个方向，换备选 C。

### 主版

```
人物上半身正对镜头，肩膀和身体全程保持静止，只有头部和颈部运动。

人物像用鼻尖在空中缓慢画一个完整的圆：从正面看向镜头开始，先微微抬头看向正上方，然后顺时针依次看向右上方、正右方、右下方、正下方、左下方、正左方、左上方，回到正上方，最后回到正面看向镜头。头部转动幅度约20度，眼睛始终看向头部转动的方向，眼神略微领先于头部。

整个过程速度均匀、缓慢、连续，没有停顿，没有加速。表情始终保持温和的微笑不变，全程不眨眼。

耳机随头部一起刚性转动，形状不变形；头发、衣服、背景、光线保持不变。纯净的浅米白色背景。

摄影机完全固定，水平视角，85mm人像镜头效果，无推拉、无摇移、无变焦、无景深变化。
```

### 备选 B：短句版（主版走不圆时试）

```
固定机位人像。人物正对镜头，身体静止，头部缓慢做一圈完整的顺时针绕圈动作，鼻尖在空中画出一个圆，幅度约20度，眼睛跟随头部方向看向四周。匀速、连贯、无停顿。保持温和微笑，不眨眼。耳机不变形，背景纯净浅米白，光线不变。无推拉摇移，无变焦。
```

### 备选 C：时间轴版（速度忽快忽慢、漏方向时试）

```
摄影机完全固定，水平视角，85mm人像镜头效果。人物上半身正对镜头，肩膀和身体全程静止，只有头部和颈部运动，眼睛始终看向头部转动的方向。

0-0.5秒：正面看向镜头，开始微微抬头。
0.5-1.5秒：看向正上方，再转到右上方。
1.5-2.5秒：转到正右方，再转到右下方。
2.5-3.5秒：转到正下方，再转到左下方。
3.5-4.5秒：转到正左方，再转到左上方。
4.5-5秒：回到正上方，再回到正面看向镜头。

头部转动幅度约20度，速度均匀连续，各方向之间平滑过渡，不停顿。表情始终保持温和微笑，全程不眨眼。耳机随头部刚性转动，不变形；头发、衣服、背景、光线不变。纯净浅米白背景。
```

> 和 Skill 原版提示词相比，只把「帽子和眼镜」换成了橘猫身上的硬配饰「耳机」，其余一字未改：每一句都对应一个踩过的坑（背景晃会穿帮、眨眼帧会像闭眼、表情中途会变……）。

## 3. 挑选标准（逐条看，全过才算合格）

1. **头真的绕了一整圈**：上、下、左、右都到位，不是只在左右来回摆
2. **从头到尾还是这只猫**：脸没走样，花纹、眼睛、鼻子都没变
3. **耳机没变形**：头梁和两个耳罩跟着头一起转，不弯、不融进毛里、不消失
4. **全程没眨眼**：偶尔一次可以接受，后面的脚本会自动剔掉

都不行时：

- 三四条都没转满一圈 → 换备选 B、C 各生成 2–3 条
- 还是不行 → 换别的支持首尾帧的视频模型（比如可灵），设置和提示词不变（这条路 Skill 没实测过）

## 4. 做完回我什么

把挑中的那条 mp4 下载下来，放到这个位置：

```
examples/orange-cat/input/绕圈视频.mp4
```

然后跟 AI 说一句：「橘猫的视频放好了，在 input/绕圈视频.mp4，继续做」。后面的处理视频、产出组件、自动验收都由 AI 接着做。
