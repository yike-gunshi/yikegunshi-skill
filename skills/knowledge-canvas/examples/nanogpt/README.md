# 示例：一个代码仓库 → 一张知识画布

日期：2026-10-22

给 knowledge-canvas 一个代码仓库，拿回一张能缩放、能平移、点开节点就能看说明和原始代码的中文知识画布。这个例子用的是 nanoGPT：一个从零训练小型 GPT 的教学仓库。

## 给了什么

- 一个代码仓库：[karpathy/nanoGPT](https://github.com/karpathy/nanoGPT)，MIT 许可
- 读取的版本：commit `3adf61e154c3fe3fca428ad6bc3818b27a3b8291`
- [input/来源.md](input/来源.md)：来源、读了哪些文件、哪些部分没有放进画布。仓库代码不复制进这里，看原始代码请走上面的链接

## 用户会怎么说

用户在 Claude Code 里说一句：

> 帮我把 https://github.com/karpathy/nanoGPT 这个仓库整理成一张知识画布。我会一点 Python，想弄懂一个 GPT 到底是怎么训练出来的。

「把仓库整理成知识画布」会触发 knowledge-canvas。

## 怎么跑的

本机未安装 knowledge-canvas，Skill 工具调不到，所以按 [SKILL.md](../../SKILL.md) 手动执行，每一步都照它和它引用的文件做，没有另起流程：

1. 读 SKILL.md 和 references 里的结构、写法、FAQ、数据格式四份说明
2. 克隆仓库到临时目录，按指定版本只读，不安装依赖、不运行训练
3. 先出对齐稿：节点清单、ASCII 草图、一个代表节点的「说明 + 样例」，见 [output/对齐稿.md](output/对齐稿.md)
4. 把所有内容写进一份画布数据，用 Skill 自带的 `build_canvas.cjs` 生成 HTML
5. 用 Skill 自带的 `check_canvas.cjs` 做浏览器检查，再用无头浏览器逐一查看总览、节点详情、文档、FAQ、辅助连线、窄屏和全屏截图

## 代确认的门禁

这次没有真人在场。Skill 里需要用户拍板的地方，由 Claude 扮演用户，读者设定为「听说过 GPT、会一点 Python、想弄懂一个 GPT 是怎么训练出来的人」，其余一律选 Skill 写明的默认值。每处一行：

- 读者与关心的问题：按上面的读者设定，问题是「文字怎样变成数字、一步训练里发生什么、模型内部怎么算、训练完怎么写字」。演示时由 AI 按默认确认
- 范围：只看训练相关的代码，测速脚本和两个分析笔记不放进画布，在说明里写明。演示时由 AI 按默认确认
- 结构对齐（节点清单、ASCII 草图、代表节点「取一批数据」）：照对齐稿生成，不改。演示时由 AI 按默认确认
- 样例怎么取证：不运行训练。代码原文、README 原文、按代码推导的数值、构造示例分别标注；README 里作者记录的运行结果标明「本次未复现」。演示时由 AI 按默认确认
- 画布类型与页签：材料是混合型，用 Skill 默认的「画布 / 文档 / FAQ」三个页签。演示时由 AI 按默认确认
- FAQ：按 Skill 规定，只收有代码或 README 依据的易混淆点，标明不是用户提问。演示时由 AI 按默认确认
- 动效：只给有依据的训练主循环配按序流动，模型结构、条件和引用关系保持静态。演示时由 AI 按默认确认
- 辅助连线：提速选项、词表文件、GPT-2 权重等辅助关系默认隐藏，用「显示全部依赖」打开。演示时由 AI 按默认确认
- 交付方式：本地 HTML，不发飞书、不发布。演示时由 AI 按默认确认

## 得到了什么

- [output/nanoGPT-知识画布.html](output/nanoGPT-知识画布.html)：一张知识画布，单个文件，离线可用
  - 画布页：准备数据 → 训练循环 → 生成文本，下方是训练和生成共用的 GPT 模型；训练循环画成一个环，内层是「梯度累积」的小回路
  - 节点详情：每个节点一段说明，加上从仓库逐行截取的代码、README 原文或推导例子，可以滚动和复制
  - 文档页：同一份内容按分组连续阅读，和节点详情逐字一致
  - FAQ 页：几个读这份代码最容易混淆的问题，每题都能跳回画布上的相关节点
- [output/nanoGPT-知识画布.json](output/nanoGPT-知识画布.json)：画布的数据真源。画布、文档、FAQ 都由它生成，要改内容就改这一份
- [output/对齐稿.md](output/对齐稿.md)：生成前的对齐稿，也就是第一道门禁确认的内容

## 怎么打开画布

双击 `output/nanoGPT-知识画布.html`，用任意现代浏览器打开即可，不需要联网。

- 滚轮缩放，拖动空白处平移，「适配全图」看全貌，「100%」回到阅读大小
- 鼠标停在节点上稍等片刻弹出详情，点击节点固定详情，Esc 关闭
- 左上「定位模块」直接跳到某一组
- 「显示全部依赖」打开默认隐藏的辅助连线
- 「暂停流动」停掉训练主循环的流动动效

从数据重新生成画布（在 Skill 目录下执行）：

```bash
node scripts/build_canvas.cjs examples/nanogpt/output/nanoGPT-知识画布.json /tmp/nanoGPT-知识画布.html
node scripts/check_canvas.cjs /tmp/nanoGPT-知识画布.html --playwright /path/to/playwright
```

## 忠于代码

- 节点详情里的代码和 README 片段，都按行号从上面那个版本逐字截取，没有改写
- 代码里没写的东西不补。比如检查点参数名前缀的来历，代码注释写的是「原因还没查清」，画布就照这么写
- 推导出的数值、构造的例子单独标注，不冒充运行日志；README 里作者跑出来的结果标明「本次未复现」
- 仓库作者已在 README 说明这个仓库过时、推荐新仓库 nanochat，本例只把它当作教学材料
