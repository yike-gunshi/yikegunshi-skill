# 视觉、写法与交互

## 页面与阅读层

- 顶部：标题、范围或版本、画布／文档／FAQ Tab
- 画布：局部结构、简短摘要、必要状态，模块导航和辅助依赖开关独立于节点
- 详情：说明 + 样例／依据，支持原文滚动与复制
- 文档：按同一份分组和节点数据生成，目录定位，解释与弹窗一致
- FAQ：有内容才显示，用户明确要求预留时显示待补充，不用虚构问答凑空页；新增或维护时按 [FAQ 写法与节点联动](faq.md) 处理

流程型可以把画布 Tab 命名为“链路”，概念型默认“画布”。切换 Tab 保留画布缩放、平移、依赖开关和文档滚动，隐藏画布时暂停动效。

## 默认视觉语言

这些是可覆盖的默认设计值，不是每份知识必须使用的主题：

| 项目 | 默认值或准则 |
|---|---|
| 背景 | 深色底、低对比点阵 |
| 配色 | 少量稳定语义色；在本图中一致，不把某个业务类别永久绑定颜色 |
| 字体 | 本地中文系统字体用于阅读，等宽字体用于代码和 JSON |
| 节点标题／摘要 | 约 20px／13px，以 100% 时可读为准 |
| 容器标题 | 高于节点层级，标题栏与内容留独立间距 |
| 内容 | 节点只放名称、简短摘要、真实英文名与必要状态 |
| 形态 | 动作圆角框、判断形状、文档折角、数据源圆柱、普通文本，按语义选择 |

颜色、字体、间距、线宽和交互延迟集中在模板变量或常量中。不要在业务数据里写 CSS 或按每个节点手工指定不同字号。

## 布局与连线减负

主关系应有明确阅读方向，分支、汇合、回路和目录各自呈现结构。并列条目可对齐，但全图不能为了整齐丢失结构差异。节点不重叠，连线不穿过节点正文或容器标题。

- 流程主线清晰，次要支线降低对比
- 局部回路尽量短，跨模块连线从明确边缘位置进出
- 组成项合并成公共汇合线，保留各组成节点，出口只画一个箭头
- 辅助引用默认不显示，通过开关整体显现，不依赖 hover 才看得清主流程
- 回复、事件或数据侧通道若影响理解，保持可见并标明其并行含义
- 图例随关系种类生成，避免堆放本图没有使用的符号

可以用 ELK 等工具辅助构建布局，也可手工调整；工具不能决定关系含义。布局计算留在构建阶段，生成 HTML 的阅读不依赖该工具或联网。

### 正交连线与折叠重排

- 先确定节点或容器的连接侧与连接点，再寻路；连线沿边界法向离开或进入，不能沿边框擦过后用极短线段拐入
- 优先直线、少量清晰折线；自动寻路将“方向”纳入状态并对转弯计价，仅按距离或网格步数优化容易生成等长阶梯线
- 跨模块主线、循环返回和辅助依赖预留可辨认的通道；标题是避让区域，路径经过多层容器时应选侧入口或调整留白，不围着文字区连续钻缝
- 端点附近保留足够直线，长度需覆盖圆角与箭头占用；先清理重复点与共线点，再圆角化，不能靠圆角隐藏密集短折线
- 箭头的几何尖端与 marker 的参考点对齐，终点接在实际形状的边界；菱形、圆柱、折角卡片须额外检查可见轮廓
- 折叠后内部线隐藏，跨边界线接可见容器的明确入口；不同条件入口保持区别，展开后重连真实内部节点，不能仅缩放旧坐标
- 组成汇合线可共享无箭头支线，多个独立调用不可因共用通道而被误画为同一条关系；降低噪声仍通过辅助线开关，不删改语义边

`route_geometry.cjs` 提供保守默认阈值：最多 6 个折点、折线路径首尾至少 16 个画布单位、中间段至少 12 个单位。它们用于暴露异常，不要求所有图使用固定方向或相同布局；复杂路径应先改通道或留白，确需调整阈值时记录视觉验证依据，不为通过检查统一放宽。自定义渲染器在折叠投影后把实际可见边和端点传入同一检查器。

## 动效

仅对有依据的流程方向配置顺序演示。概念图默认无动效，组成、引用和条件线默认静态。一个步骤可以并行多条线，不因少光点的目标强行改成串行。

保留少量按序推进的箭头，去掉每条线独立循环的背景粒子。演示计划与真实运行日志分开，页脚标明动效不证明实际执行。提供暂停，遵循 prefers-reduced-motion；未配置动效时隐藏播放按钮。

静态 SVG 与动效 SVG 分层，共用 viewBox 和坐标，不对包含所有文字的大图反复做 CSS transform。线条用非缩放描边，移动符号按屏幕大小补偿；避免大面积 glow／filter。动效经过节点时用遮罩隐藏，不能覆盖文字。

## 说明与样例写法

说明用 **加粗要点：** 接正文；多项内容用无序列表，可按真实层级嵌套。标签与一段正文保持同一行，不将每个标签和正文各拆成项目符号。简短条目默认不以句号或分号结尾，原文和长段引用保留本身标点。

不凑固定栏目和数量。用通俗词解释机制、概念和关键区别；来源与核验范围放说明之后，原始样例单独呈现。

样例块按材料标为输入、输出、原文、例子、反例、前提、推导等。JSON、代码、Markdown、引用和公式均可以保持原始文本，格式标签说明类型，不强制 JSON 包装。页面必须转义原始 HTML，不执行材料中的脚本或事件属性。

## 交互默认值

- 默认 100% 阅读；适配全图和模块定位由用户主动选择
- hover 600ms 打开，快速划过或开始缩放、拖动时取消
- 离开节点后延迟 320ms 关闭，移入浮层继续阅读
- 点击固定、Esc 与关闭按钮退出；支持触摸点击和键盘聚焦、Enter、Space
- 浮层宽度上限 455px，自适应可见窗口，正文与长样例可分别滚动
- 每次打开节点时，正文和样例滚动位置归零；固定详情时不会被别的 hover 抢占
- 复制返回所选样例原文，不复制格式化后的近似版本；剪贴板受限时选中文本供手动复制
- 缩放、平移共同作用于容器、节点和连线，resize 不重置视角
- 独立页面使用可用窗口；嵌入正文默认 640px 画布，全屏时填满剩余空间
- 全屏请求应用容器自身，包含弹窗和操作栏；操作栏占独立空间，不悬浮遮挡画布
- 全屏不可用时解释限制，不假装已扩展宿主窗口

## 验收

使用数据驱动检查，不硬编码节点数、节点名、业务场景或当前版坐标。检查图中节点都有说明，文档与弹窗一致，样例原文不变，引用与分组有效。

实际查看总览、主线、组成汇合、辅助依赖开启、详情长内容、文档、FAQ、390px 窄屏、矮屏和全屏。检查标题溢出、连线穿框、浮层边界及控制区占位。

连线验收同时核对数据路径和圆角后的 SVG：端点贴边、进入方向正确、箭头前有直线、箭头未被节点遮住、折点不过密。支持折叠时覆盖默认、全部展开、混合折叠及深链接展开状态，检查到当前可见容器的接线；静态路径、箭头与动效必须使用同一份投影路径。保留短末段、切向接入、端点悬空和阶梯线的失败样例，证明检查器能拦截它们。避障通过、可读性通过、人工截图审查分别报告。

交互回归覆盖 hover 延迟、取消、固定与 Esc、键盘、复制、滚动归零、Tab 状态、缩放与平移、模块定位、辅助依赖、减少动态效果、嵌套 iframe 全屏与拒绝说明。动效修改后用含 48% 的非整数缩放做静态区域帧对比，不把浏览器本地通过称为真实宿主已验收。
