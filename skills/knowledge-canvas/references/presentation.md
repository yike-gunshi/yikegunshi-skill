# 视觉与交互

## 画布

- 深色底与低对比点阵，节点按语义使用稳定配色；使用本地中文系统字体，技术数据用等宽字体
- 默认节点标题约 20px、摘要约 13px，初始缩放 100%；大图可拖动、定位模块或主动适配全图
- 处理动作、判断、文本产物、数据源使用可辨别形态，允许多级容器
- 所有范围内的重要最小节点显式展示，不把子模块藏进详情
- 节点只放名称和必要摘要；操作提示、测试计数和加载状态不放在节点或常驻页脚

布局中的尺寸与示例坐标可按内容调整，关系语义、原文完整性及可读性优先于机械复刻坐标。

## 详情

“说明”和“样例”两部分；样例内部区分“输入 JSON”“输出 JSON”。

说明用加粗要点后接正文，如“用途：找到本次问题相关的资料”。多条并列内容用无序列表，层级表示真实从属，不将标题与正文拆成两份列表。不在说明文案末尾加句号、分号；此规则不修改原始样例。

样例默认直接显示完整 JSON。来源原本是字符串、Markdown 或 XML 时按原文展示，必要的 JSON 包装明确为展示结构。不要为阅读方便改写其字段值。页面使用 textContent 或可靠转义插入原文，原文中的 HTML 与脚本作为文本，不执行。将资料嵌入 script 时先用 JSON 序列化，再把小于号转义为 \\u003c，防止原文中的结束标签提前关闭脚本；精确 JSON 原文优先作为字符串保存。

来源类型与必要位置放详情底部。数据较长时滚动显示，宽度受限时允许横向滚动；不为缩短浮层裁剪值。资料有敏感信息或版权限制时先确认可分享范围，脱敏后的示例明确标注，不再称未修改原文。

## 交互

- hover 600ms 打开，快速划过取消；移入浮层可继续阅读，移出延迟 320ms 关闭
- 点击固定，关闭按钮与 Esc 关闭；触摸可点击，键盘可聚焦与打开
- 浮层宽度上限 455px，随容器宽高限制，长说明与样例可以滚动
- 缩放和平移同时作用于节点、连线、容器；100% 与适配全图分开
- 模块定位根据实际范围生成，不硬编码某个项目的模块名
- resize 不重置用户缩放，全屏前后的内容状态保持
- 全屏容器包含详情浮层，标题与操作栏独立占位，中间画布使用剩余空间
- 全屏成功时保留“退出全屏”按钮即可，正常界面无重复状态提示；拒绝时才解释原因

## 验收

检查总览关系和节点覆盖后，实际操作 hover、快速划过、固定、Esc、缩放、平移、模块定位、全屏进入与退出。测试常规桌面、约 390px 窄容器及矮屏，检查浮层边界、样例完整性和底部工具栏。

嵌入场景增加嵌套 iframe 与全屏允许/拒绝测试。等待真实全屏事件及布局稳定后验证，避免把固定短延迟当作成功。自动检查覆盖交互与几何边界，不能证明内容抽象正确。
