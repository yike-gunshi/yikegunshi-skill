# 示范例子：番茄钟网页里派给 Codex 的代码任务

codex-delegate 的例子长在 Forge 示范项目里：用 Forge 把一个番茄钟网页从一句想法做到上线，其中写代码的几步由 Claude 写任务书、派给本机 Codex 写，Claude 按任务书里的验收标准逐条核对后才提交。

- 过程记录（任务书怎么写、派了几次、验收和返工）：[forge-skills/examples/pomodoro/codex-delegate.md](https://github.com/antonailog/forge-skills/blob/main/examples/pomodoro/codex-delegate.md)
- 示范项目仓库（代码、需求、验收报告都在里面）：[antonailog/forge-demo-pomodoro](https://github.com/antonailog/forge-demo-pomodoro)
- `shots/`：配图用的输入（任务书的验收标准）和输出（Codex 写好、Claude 验收过的代码）截图

示范里需要用户拍板的地方由 AI 按事先写好的需求设定代为确认，记录里每一处都有标注。日期 2026-10-23。
