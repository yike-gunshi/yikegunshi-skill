# 场景模板：OKR / 定位与季度目标

适用：季度或阶段性的定位与目标文档，向上对齐加团队拉齐用。目标未定稿的初版讨论稿同样适用，未定状态显式写出即可。单业务线的轻量目标文档可裁剪使用（保留定位加目标 callout 两段，附录按有无摸底数据取舍）。

## 文档组织

- 单篇独立文档，标题即定位加目标（如 产品A定位及Q3目标），不做多期堆叠
- 信息流向锁死：定位 → 目标 → 支撑盘点 → 附录摸底。结论极简置顶，正文主线几百字讲完定位和目标，论据与原始数据全部沉附录
- 重资产用嵌入不用复述：画板（whiteboard）放定位图、能力地图、指标漏斗；sheet 放需求大表、进展表。本地 markdown 用注释占位（此处为 whiteboard：定位图），发布时挂真实嵌入

## 固定骨架（顺序锁死）

1. `# 定位`：开头就是等式定义句加加粗，一行说清本业务是什么、目标是什么。后接支撑动作的编号列表：需求盘点（sheet 嵌入需求大表）、入口定位（whiteboard 嵌入定位图），每条一段短逻辑
2. `# Q3目标（初版）`：目标本体整体装进 callout。callout 内第一行是加粗的总目标一句话，下挂最多三条编号加粗目标，每条目标带指标基线和留白（48%→xx），子项拆打法并责任到人
3. `## 能力盘点`：whiteboard 嵌入能力地图，正文不展开
4. `## 现有skill进展`：sheet 嵌入进展总表；下设 H3 放效果对比，竞品对比用表格加多列截图
5. `# 指标体系、数据漏斗`：whiteboard 嵌入漏斗图，实验元信息（实验链接、分组）放引用块
6. `# 附录：各类需求摸底`：按自家数据 → 竞品分 H2，每节首行先给数据来源和抽样口径，明细进表

## 模块写法

- 目标条目形态：编号加粗，动作加指标加基线留白（降低01分badcase 48%→xx），口径用括号紧跟（搜索uv/进入IM的uv）。子项按打法拆（负向优化、正向引导），尾部挂 @负责人 或 with @负责人
- 未定内容不藏：目标写明初版，条目内直接写（具体目标再想想）、待定（with @负责人 对齐中），不硬凑数字
- Todo 用斜体内嵌在对应内容下方，不另开章节：*Todo：需求场景的分类再打磨一下，不宜过粗or过细；看看真实原声case*
- 竞品对比表：行是细分场景乘 query，列是各竞品加自家方案，单元格放截图加一行点评，点评直接下判断（实效性有问题，最新视频是8.5；不出卡）
- 附录数据表：需求大类 → 一级分类 → 二级分类逐层给占比，典型 case 放截图列；数据来源行必须带条数、剔除口径、抽样方式和链接
- 用户原声用代码块保真引用，符号照原样保留

## 语气要点

- 口语化程度全场景最高：搞一版demo、再想想、拉胯、大头是这类口语照写，定位文档要的是判断清晰不是措辞工整
- 定义句用等式表达：产品A的定位=主站的AI。一行等式压过一段铺垫
- 允许降级表述：初版、疑似、推测、WIP中，判断未稳时显式标注而不是装确定
- 责任到人贯穿目标区：每条打法子项都落到 @人，没有人认领的目标不写进 callout

## 精选片段（学结构和语气，别照搬内容；名称、人名、数字均为虚构示例）

定位段的等式定义句：

> **产品A的定位=主站的AI**
>
> **产品A的目标**=用户在主站，对AI有潜在需求的场景，**我们做出4分体验、带动端留存增长**

目标 callout 的形态：

> （此处为 callout）
> **Q3目标：产品A IM的体验达到基础水位、支撑一波放量**
>
> 1. **基础体验优化，降低01分badcase 48%→xx**
>    1. 占比最大的知识问答需求，在原子化能力base上，优化策略效果（with @负责人A）
>    2. 引入各场景基础能力，包括经验决策、功能咨询、搜账号/搜视频、视频总结 4大类skill
> 2. **人群和能力引导，提升IM内的搜索转化率 3%→xx**（搜索uv/进入IM的uv）
>    1. 负向优化：C端收紧历史记录的记入逻辑 @负责人B
>    2. 正向引导：待1的能力ready后（9月初），做一次冷启引导，主动告知用户产品A IM的能力 @负责人C
> 3. **从旅游规划切入，探索4分case，先搞一版demo（具体目标再想想）**

附录数据来源行加竞品占比压缩段的形态：

> 数据来源：27-30号全量1200条线上query，剔除测试用户后1000条query，随机抽样100条（抽样sheet链接）进行统计
>
> 竞品A需求占比：泛搜索75%（大头是客观知识）、写作8%、其余长尾
>
> 竞品B需求占比：知识50%、复杂专业咨询26%、创作12%
