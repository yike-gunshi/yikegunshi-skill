# 通用写法约束

任何场景的文档都先过这一层，场景模板在此之上叠加。约束来自用户 8 篇认可范文的跨篇分析，每条都写了 why：遇到模板没覆盖的情况，按 why 推断。

## 结构与布局

1. 结论先行，证据后置。读者是老板和协作方，30 秒内要扫到结论。结论、统计、目标放章节最前（文档头、汇总表、标题内），过程和原始数据沉到下方、附录或外链。任何一节都不允许过程先行。
2. 表格是默认信息载体。凡是多对象乘多属性的信息（指标、case、todo、对比、排期），一律进表，不写长段落。段落只用于单线叙述。
3. 文档头定调。开头用一句话说清本文是什么、核心结论或核心逻辑是什么（飞书落地为 callout；本地 markdown 用引用块占位并标注 callout）。
4. 引用块承载元信息。口径说明、抽样方式、设计理由、上级论述放 blockquote，与执行内容视觉区隔，读者可跳过不影响主线。
5. 外链代替复述。细节链到子文档、看板、trace、sheet，正文只留一行结论；每个数据必附出处链接。链接文字用文档名或描述，不裸贴 URL。
6. 明细与附录沉底。案例、原始输出、延伸材料统一收文末附录或外链，不混进主线。

## 数字与事实

7. 加粗只给指标名、数字、结论词，不给整句。满屏加粗等于没有加粗。
8. 数字带对比基线：写 3%→7%、-60pp、1.8→2.8，不写孤立数字。目标未定时用 →xx 留白占位，不空着也不编。
9. 未完成项显式标注。todo 用表格或斜体内嵌，已完成用删除线，待定写明待定或 wip。不隐藏未完成状态，暴露风险是文档的功能之一。
10. 主观判断必带依据或降级词：推测 xx，排查中；1% 采样不置信；建议与 xx 核对。没有依据就不下断言。

## 语气与句式

目标是阅读通顺：句子里主语和动作先出现，读者尽早知道谁做了什么，再接时间、原因、条件。

11. 压缩句式。用名词短语加冒号加数据或状态（入组 uv 12,345，曝光渗透 45.6%），不追求完整句。箭头（→）表达流程和传导。例外：教学与方法论类文档用完整句叙事。
12. 责任到人。@人挂在标题尾部或条目尾部，不在正文句子里提名字。
13. 正文禁用装饰符号：角括号（「」）、弯引号（中英文弯引号同理）、方头括号（【】）、长破折号（——）、下划线强调（_）。这些符号做行内强调或插入会打断阅读，改为结构化分点：标题、分级 bullet、冒号加子项。标注专有名词、模块名、字面串用行内 code。范文里的方头括号标签（如【产品A IM】）属历史写法，不再沿用，改为加粗场景名。例外：原文保真的引用（用户原声、模型回答原文、证据摘录）保留原样；文件名里的下划线分隔符不受限。
14. 不写路标套话和自指。不写以下是、综上所述、本文将介绍、值得注意的是、需要指出的是；不写同步给大家、周知。直接说内容。
15. 不写翻案腔。不是 A 而是 B、看似 X 实则 Y、与其说不如说，这类句式先立一个读者没有的误解再推翻它给下文抬价。判断从正面下：先给判断，再给依据。换字面做同一个动作也算命中。
16. 动词不名词化。完成了对流程的优化，写成把流程改顺了；实现了效率的提升，写成快了多少、省了几个人。名词化是汇报腔的主要来源。
17. 不用抬价黑话。赋能、打造、彻底改变、构建抓手这类词不用，普通事情用普通词说。
18. 同构排比最多两项，第三项换一种说法或删掉。整齐的排比读起来像口号不像信息。

## 飞书落地注意

产出的本地 markdown 要能被 lark-cli 导入飞书，注意：

- 简单表格用 pipe 表；含合并单元格、单元格内多行或块级内容的表格整表用 HTML table
- HTML 表格单元格内换行用 br 标签；单元格内不用 markdown 列表语法，用 • 加全角空格缩进
- 正文出现字面尖括号时转义，代码块内不转义
- callout、@人、whiteboard 等 markdown 无法表达的块，在文中用注释标注（例如：此处为 callout），发布时人工或脚本处理
- 发布到飞书的文档，文内引用一律用可点击超链接：外部来源挂原始 URL，内部细节挂子文档链接；不出现本地文件路径
- 涉及结构化表达、层次化内容（流程、分层、树状、闭环、对比选型）时，默认配一张图辅助理解：飞书落地为 SVG 画板，风格与字号按使用者自定义的画板规范统一执行；本地 markdown 用 mermaid 或画板占位注释

## 终审清单

交付前逐条过，不过的改完再交：

- [ ] 装饰符号清零（角括号、弯引号、方头括号、长破折号、下划线强调），保真引用除外
- [ ] 每节结论在最前，无过程先行
- [ ] 多对象多属性信息都进了表
- [ ] 数字都带基线或标注了留白
- [ ] 数据都有出处链接，链接都是用户提供的真实链接
- [ ] 待定与未完成项都显式标注
- [ ] 无路标套话、无自指、无无依据断言
- [ ] 无翻案腔、无动词名词化、无抬价黑话、无三项以上同构排比
