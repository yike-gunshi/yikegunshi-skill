# 场景模板：双周报收集（周报todo）

适用：一个方向的多个例会（周会、双周会）汇报材料收进同一篇文档，按期堆叠、Todo 闭环到人，面向老板和跨团队参会方。单个会议的完整周报走模板_周报，本模板管多会议汇总加 Todo 追踪的形态。

## 文档组织

- 多期倒序堆叠在同一篇文档：新的一期写成新的 H1（日期加会议名，如 8.4产品A周会、7.27 双周会）置顶，旧期下沉不删
- 文档最顶部维护一个跨期不动的 callout：各例会元信息（周报文档链接、例行时间、更新 DDL、参会方式），只在会议机制变化时更新

## 单期固定骨架（顺序锁死）

1. 期头 callout 承载本期 Todo：编号列表，每条挂 @人，嵌套编号列表拆子任务；子任务写到可执行粒度（做什么加为什么）
2. 正文按方向模块分 H2（如搜索Tool、多轮对话、IM、AI 助手），标题尾部挂 @负责人
3. 期末列下期 Todos：编号列表按主题分组，与期头 callout 首尾呼应，下期开会逐条对账

## 方向模块（H2）写法

- 结论等于指标变化加动作状态一句话（先验优质率80%、后验CTR2.2%、本周推全、下周回收），归因短评紧跟（收益来源于视频需求下答案卡过召问题优化）
- 一段内塞多个并列点用带圈数字 ①②③，不拆成松散 bullet
- 证据紧挨结论下方内嵌：截图、sheet、trace 链接放在对应结论正下方，不集中收文末
- 数据来源用引用块小字注明抽样口径：哪几天、全量多少条、剔除什么、抽样多少条
- 引用块还承载方向定义和老板视角论述，与执行进展区隔
- 多问题归因用大表：问题类型、数量占比、典型 case 带 trace 链接、进度、优化效果、关联文档一张表收完；表格内可嵌图片做效果对比，竞品对比截图用分栏（grid）并排
- 加粗只给指标名和结论词（本场景加粗密度全库最高，但仍不给整句）
- 已作废事项用删除线保留，不删除

## 语气要点

- 数据汇报体：句子高度压缩，名词短语加数据加状态连排，不追求完整句
- 结论先行且量化，数字带基线或对比（+30pp、12→8、1/10→4/10）
- 风险和依赖显式写进正文：量级日均不足400条、依赖新架构上线、具体时间未知，这类话照写
