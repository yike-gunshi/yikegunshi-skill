# 终审门（成稿后跑，起草时不看）

四层按序跑。第一层不过，后面三层不用跑——风格再像，事实是编的就整篇作废。

## 一、事实审计

逐句列出素材之外的细节：场景、动作、身体反应、对话、数字、时间。每条三选一处理：

1. 换成素材里已有的细节
2. 占位标注 `【需要你的真实经历：…】`，只放非承重位
3. 改诚实模糊（"具体多久我记不清了，反正用了挺长时间"）。诚实模糊也是人话，而且往往更像人话

判断方法：写下的每个细节问一句，这是他给的，还是我补的。

小红书最容易编的三样，逐一回到素材里确认：**时间点**（"上周三凌晨"）、**数字**（"效率提升 3 倍""十次有八次"）、**心理活动**（"我当时就愣住了"）。

## 二、句式排查

下面每一类，搜到就按右列改。判断标准是功能不是字面，功能相同的变体一样算命中。

| 类别 | 例子 | 改成 |
|------|------|------|
| 二分对照壳 | 不是 X 而是 Y、与其说…不如说…、重要的不是…而是… | 直接说 Y |
| 对称格言 | 前后半句工整对仗的判断句 | 保观点破对仗，后半句落到具体事上 |
| 同义反复对仗 | 榜是榜，活是活 | 换成有信息量的话 |
| 路标套话 | 首先其次最后、值得注意的是、不难发现、综上所述 | 删掉，直接说 |
| 假深刻口头禅 | 说白了、本质上、换句话说、归根结底、这意味着 | 直接说事 |
| 分析动词堆叠 | 拆解、梳理、剖析、解构、洞察、深耕 | 换白话，这几个是 AI 中文的签名词 |
| 伪口语小动作 | 盘一盘、捋一捋、划重点、敲黑板 | 删，这是假装接地气的讲义腔 |
| 宣传腔 | 赋能、打造、极致体验、重新定义、彻底改变 | 换成具体做了什么 |
| 万能结尾 | 未来可期、拭目以待、你觉得呢、欢迎留言讨论 | 换成真实感受 + 求经验，见 voice.md 收尾三件套 |
| 极值句式 | 真正可怕的是、最残酷的是、最戳我的是 | 把那个具体事实直接写出来 |
| 空泛工具名 | AI 工具、某个模型、相关技术 | 写具体名字 |

再扫三样格式：正文里的 emoji、加粗、markdown 标题。小红书正文不渲染 markdown，星号和井号会原样显示出来。

## 三、声音校对

对照 voice.md 的 12 条硬手迹，重点查这四条最容易在改写中被"规范"掉的：

- 段末保持不加句号
- 术语保持小写口语（cc、ai，而不是 Claude Code、人工智能）
- 清单项保持口语句（而不是"标题：解释"的工整格式）
- 结尾保持真实感受 + 求经验（而不是"赶紧去试试吧"）
- 转场、段尾、互动句这三处保持大白话，成语和自造比喻在这里一个都不要，见 voice.md 的"接缝处不使劲"

再扫一遍 voice.md 的"他不会说的话"。

## 四、活人感

以读者视角通读，回答一个问题：**这像一个自己做工具的人在跟同行交换经验，还是像一篇工具推广文案？**

看五点：

- **读者拿得走什么**：数一下正文里属于"作者个人处境"的句子。超过两三句就压缩，版面留给读者能用的判断和动作，标准见 voice.md 的"写给读者，不是写日记"
- **情绪是体感还是词库**："用了很久，效果真的很好"是体感，"极大提升了我的效率"是词库
- **有没有编不出来的细节**：至少一个具体到别人写不出来的东西（旧副本躺了近一个月、勾选想学哪几个）
- **有没有承认不足**：全是优点读起来就是广告。他自己没提缺点时保持原样，但值得提醒他补一句
- **心流**：从头读到尾有没有卡住、需要回头理逻辑的地方

## 五、回滚检查

改完对比上一稿。信息密度下降、句子长度变匀、锋利判断被抹平、具体细节丢失，就退回重修。无菌的白开水和留着 AI 味一样是失败。
