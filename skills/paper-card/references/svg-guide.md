# 结构图 SVG 规范

## 设计原则

1. 底板结构与卡片正文板块一一对应：机制或流程一块、关键数字一块、消融或可靠性一块、启示或对应关系一块。图是卡片的可视化目录，先看图有全貌，再读文字看细节
2. 数字带读法进图：不只写 0.709，同一张卡片里写明医生互评 0.57 到 0.73、模型落在人类区间。图要独立可读，不依赖正文
3. 全图唯一一处浅黄高亮，给这篇工作最值得记住的一件事
4. 图的重心跟随类型：方法论文画闭环和消融，工程实践画结构和数字对标，官方文档画建议清单和使用流程

## 视觉规格（分层底板卡片风）

- 画布白底，宽 1240 上下，高按内容 900 到 1100
- 左上角标题 22 到 23px 加粗深黑，下方一行灰色副标题概括主链路，用箭头串联
- 分组底板：大圆角浅蓝灰 `#f1f4f9`，圆角 14，描边 `#e2e8f2`；底板标题行等于蓝色小圆角竖条加粗黑标题加灰色小字注解
- 节点是白色圆角卡片：圆角 8，描边 `#d9dee8` 1.5px，卡片内两行式：加粗黑主标题 15px 加灰色说明 14px
- 强调节点：`#2563eb` 描边 2px 加极浅蓝填充 `#eef4ff`
- 唯一高亮节点：浅黄底 `#fdf3d8` 加琥珀描边 `#d9a514`
- 连线：灰色 `#8a94a6` 1.5px 正交折线；关键链路用蓝 `#2563eb`；线旁可挂灰色小字标签
- 箭头必须用 path 手绘实心三角（形如 `<path d="M x y l-9 -5 v10 z"/>`），SVG marker 会被飞书画板丢弃
- 全部文字 font-size 不小于 14px，字体 `PingFang SC, Noto Sans SC, sans-serif`，不用阴影
- 对照组、基线类节点可用虚线描边 `stroke-dasharray="6 4"` 区分

## 渲染自查

画完必须截图亲眼看，文字溢出和箭头错位只有看渲染结果才能发现：

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless --disable-gpu \
  --screenshot=check.png --window-size=1240,{svg高度} "file://{svg绝对路径}"
```

然后用 Read 工具查看 check.png。检查四项：文字是否溢出所在卡片、箭头起止是否贴合卡片边缘、底板之间是否重叠、黄色高亮是否全图唯一。qlmanage 缩略图会裁切右侧，不要用它做自查依据。

发现溢出时优先缩短文案，其次加宽卡片，不缩小字号到 14px 以下。

## 飞书落地

- 本地 markdown 交付：SVG 文件与 md 同目录，md 里用相对路径内嵌图片
- 飞书交付：用 lark-cli 将 SVG 以画板形式插入，`<whiteboard type="svg" path="@xxx.svg"></whiteboard>`，从 SVG 所在目录执行命令使相对路径可解析
