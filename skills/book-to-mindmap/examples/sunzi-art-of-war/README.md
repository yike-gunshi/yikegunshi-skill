# 示例：《孙子兵法》→ 一张思维导图

日期：2026-10-22

给 book-to-mindmap 一本书，拿回一张能扫一遍掌握全书主张、点开才看细节的导图。这个例子用的是《孙子兵法》全文。

## 给了什么

- `input/孙子兵法.md`：《孙子兵法》十三篇原文，公有领域。
- 来源：维基文库「孫子兵法」页 <https://zh.wikisource.org/wiki/孫子兵法>，用维基文库自带的简体转换显示后转成纯文本。
- 维基文库这一页末尾还附了「答话」，是后人辑录的佚文，不属于十三篇，没有收进输入。

## 怎么调用的

用户把原文交给 Claude，说一句：

> 这是《孙子兵法》全文，我没读过，帮我做成一张思维导图，要 xmind。

「做成思维导图」会触发 book-to-mindmap，之后按 Skill 的流程走：定覆盖档 → 定骨架给用户确认 → 逐支填写 → 写备注 → 查遗漏 → 交付。

## 代确认的门禁

Skill 里要用户拍板的地方，这次由 Claude 扮演用户、按「读者是没读过原书的普通人」来判断：

- **覆盖档**：选精读替代版（Skill 默认）。读者没读过原书，所以原文里每一段实质内容都要在导图里有位置。
- **画布**：整本书放一张画布。Skill 默认一章一张画布，这里按用户原话「一张导图」来；这本书篇幅短，十三篇按主题重组后放在一起也不拥挤。
- **骨架**：确认，但改了几处，初稿见 `output/骨架稿-v1.md`。
  - 一级分支一律改成白话：「不可胜」改成「不被打败」，「以迂为直」改成「绕远路反而能先到」，「虚处」改成「薄弱处」，「借势」改成「造势」。原书术语挪到下一层，在备注里解释。
  - 只报话题的枝干改成判断：「用兵有八条禁忌」→「八种情况不能硬碰，被围之敌要留缺口」，「火攻有五种目标」→「火攻的目标有人、积、辎、库、队五种」，「地形有六种」→「六种地形，要看能否往返、谁先占领」，「将领有五种危险的性格」→「将领性格走极端，就会被敌人利用」。
  - 逐支填写时又顺手微调了几个枝干的措辞，以 `output/孙子兵法.md` 为准。
- **查遗漏深度**：程序对账加只看导图答题（精读替代版要求做到这一层）。答题交给一个看不到原文的子 agent，过程和结果见 `output/查遗漏记录.md`。
- **折叠层深**：第 2 层（Skill 默认），打开先看到全书骨架。

## 得到了什么

- `output/孙子兵法.xmind`：一张逻辑图，用 XMind 打开。
- `output/孙子兵法.md`：同内容的多级 bullet Markdown，是导图的真源，.xmind 由它生成。
- `output/骨架稿-v1.md`：门禁确认前的骨架初稿。
- `output/查遗漏记录.md`：覆盖检查的做法、结果和题目。

导图没有照原书篇目顺序排，改按读者会问的问题重排：要不要打、最好怎么赢、为什么要快、凭什么赢（先立于不败、造势、牵着敌人走）、怎么知道敌情、怎么抢先机、怎么用地形、深入敌国怎么打、火攻怎么用、将帅该是什么样的人。散在各篇的同一类内容收到一起，比如地形相关的内容原本分在行军、地形、九地、九变几篇里，这里合成一支。

每条知识分两层放：

- **节点**：一句白话判断，能判真假。
- **备注**：第一段是白话解释，在 XMind 里以灰字直接显示在节点里；后面附对应原文，点开备注图标才看到。

其他标注：

- 节点后的 `§N` 是出处，N 是原书第几篇（§1 始计 … §13 用间），根节点的备注里有对照表。
- 蓝字是原书术语。
- 四种标记：红星是全书最该记住的几条主张，感叹号是反直觉或易错的地方，信息图标是带关键数字的地方，问号是原文有异文或历来有不同读法的地方（备注里写明了两种说法）。

## 真源格式

`output/孙子兵法.md` 用的是 Skill 的真源语法：`- ` 行是节点，2 空格缩进一层；节点下面 `> ` 开头的行是备注，`>` 单独一行是分段；行尾 `@核心` `@注意` `@数据` `@问题` 是标记，`§N` 是出处；`**…**` 是蓝字术语。

从真源重新生成 .xmind（在 Skill 目录下执行）：

```bash
python3 scripts/mindmap-lint.py examples/sunzi-art-of-war/output/孙子兵法.md
python3 scripts/md2xmind.py examples/sunzi-art-of-war/output/孙子兵法.md examples/sunzi-art-of-war/output/孙子兵法.xmind 2
```

## 忠于原文

- 备注里的每段原文都逐字核对过，能在输入原文里找到。
- 白话释义按通行理解写。原文没解释的名词（比如天井、天牢这几种险地）照实写「原文只列出名称」，没有补。
- 有几处原文可以两读，比如「将听吾计」的「将」、「火队」的「队」，标了问号，备注里两种说法都列出来。
