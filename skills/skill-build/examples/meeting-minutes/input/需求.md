# 需求原话

> 每次开完会，我都要把会议录音的转写稿整理成会议纪要：结论、待办（谁、什么时候做完）、没谈拢的问题。能不能做成一个 skill？

除这句话外，没有提供现成的纪要模板、转写稿样本或其他材料。

## 演示用的场景设定

访谈时，提需求的人由 AI 按下面这份设定扮演，回答保持前后一致：

- 一个普通公司的项目负责人，每周开几次会，用飞书妙记或类似工具拿到转写稿（口语化、有人名、有跑题、有「嗯啊」）。
- 纪要发到群里给参会人看，要一眼看到结论和待办；待办必须有负责人，没说清负责人的要标出来，不要猜。
- 最怕：把没定的事写成定了；漏掉待办。
- 不需要接任何外部系统，输出 Markdown 即可。

设定没覆盖到的访谈问题，由 AI 选 Skill 写明的默认做法回答，在 README 里逐条标「演示时由 AI 按默认确认」。
