# 竞品档案字段

每个维度一张 CSV，存 `research_notes/<课题>/40-dossier/<表名>.csv`。每家竞品一行（价格表每个档位一行），所有对象填同样的字段。

通用约定：

- 第一列是对象名；最后两列固定为「来源」（编号，多个用分号，如 `171;2`）和「日期」（数据所指时间或抓取日期）。
- 研究员写笔记时来源还没编号，「来源」先填 URL，多个用分号；`build_source_table.py` 合并编号后，由验证者替换成编号。
- 查不到写「未查到（试过：X、Y）」，不留空。
- 数字写原始口径，不换算；需要换算的另起一列写「折合美元 / 月」并在表名后的说明里写汇率与日期。
- 用 `scripts/render_table.py <csv>` 渲染成 md 表，它会拒绝空格子和没有来源的行。

按对象类型取用：产品类用全部七张；AI 工具类把「规模」「收入」换成「项目基本面」，并加「重叠度」；公司类以「融资与团队」「合规」为主。

## 1 功能

| 字段 | 说明 |
|---|---|
| 产品 | |
| 核心形态 | 如：多角色平台 / 单一伴侣 / 助手 |
| 记忆 | 有无、长度或机制 |
| 语音 | 有无、是否实时通话 |
| 图片 / 视频 | 生成、头像、视频 |
| 群聊 / 社区 | |
| 用户自建内容 | 能否自建角色或内容 |
| 平台 | iOS / Android / Web |
| 来源、日期 | |

## 2 价格

| 字段 | 说明 |
|---|---|
| 产品、档位 | 免费版也单列一行 |
| 价格 | 原币 + 计费周期（月付 / 年付 / 买断 / 按量） |
| 折合美元 / 月 | 年付折月；人民币按表头写明的汇率 |
| 地区 | 价格看的是哪个区 |
| 核心权益 | 消息额度、记忆、语音、图片 / 视频、免广告、模型档位 |
| 免费版限制 | 仅免费行填：每日条数、等待、广告 |
| 来源、日期 | 优先官网定价页、应用商店内购列表 |

## AI 工具类专用

- **项目基本面**：项目、Stars、创建时间、最后提交、语言、许可证、作者、来源、日期
- **重叠度**：项目、对照的本机工具、关系（重叠 / 互补 / 独有）、说明、来源、日期
