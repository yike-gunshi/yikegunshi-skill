# 置信度判据

验证者定级、协调者组装时复核。标签只有三档加一个"未查到"，不发明新档。

| 等级 | 判据 |
|---|---|
| 【高】 | ≥2 个相互独立的 evidence family，且至少 1 个一方来源（官网、财报、招股书、应用商店页、原帖、官方公告、源码） |
| 【中】 | 1 个 family 的一方来源；或 ≥2 个二方来源（媒体、研报摘要、分析文章）说法一致 |
| 【低】 | 单一二方来源；或由事实推断得出（必须写明推断链） |
| 未查到 | 不进任何结论，进「存疑 / 待查」并写渠道与原因 |

## 独立性（evidence family）

- 多篇文章转引同一份报告或同一次发布 = 1 个 family。
- 同一公司的官网、公告、创始人访谈 = 1 个 family（都是一方口径）。
- 同一媒体集团的多篇报道 = 1 个 family。
- `build_source_table.py` 按域名初分 family，验证者按内容修正（不同域名转引同一报告要合并）。

## 封顶规则

- 流量、下载量、月活、收入、付费率等，在没有付费数据接口（AIsa / Sensor Tower / SimilarWeb API）或一方披露（财报、官方公告）时，**封顶【中】**。媒体转述再多也不升高。
- 预测类数字（"预计 2027 年达到…"）封顶【低】并标"预测"。
- 推断类结论封顶【低】。

## 降级规则

- 来源复核时不可达：降一级并记录可达时间。
- 来源与结论口径不一致（年份、地域、定义）：降一级并在结论里写明口径。
- 对抗分析员找到了有来源的反证：不自动降级，但结论必须改写为包含反证的版本，或拆成两条。
