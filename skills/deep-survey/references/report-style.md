# 报告文风

读者是从没接触过这个领域的聪明人。他不缺智商，缺背景；他时间有限，要的是每一句都带来新信息。

## 顺序：从入门到判断

先结论（让他知道往哪看）→ 这是什么（建立概念）→ 谁在做（认识玩家）→ 发现了什么（理解格局）→ 风险（知道哪里会错）→ 对他意味着什么（能做决定）。后一节只用前面已经讲过的概念；第一次出现的术语当场用半句话解释。

## 密度

- 每句至少带一个新事实：数字、名字、时间、因果、对比。"这个赛道竞争激烈"没有信息；"337 款有收入的应用里，前 10% 拿走 89% 的收入 [1]"有。
- 一个事实只出现一次。先看结论里讲过的数字，后文要用就引用"见第三节"，不再重述整句。
- 删掉过渡语和意义阐释："值得注意的是""综上所述""这说明了……的重要性"。
- 每节第一句就是该节最重要的话。
- 正文（不含来源）目标 2500—4500 字。写多了先删"关键发现"里最弱的一条，再删玩家卡里的第四行。

## 可信度用文字交代，不贴标签

正文不出现【高】【中】【低】。按下面写：

| 情况 | 写法 |
|---|---|
| 官方披露（财报、招股书、官网、公告） | 直接写，不加修饰 |
| 第三方统计或估算 | "据 Appfigures 统计""第三方估算"——点名谁算的 |
| 多个来源说法不一 | 给区间并说明分歧来源，一句话 |
| 推测 | "推测""可能"，并给出推测依据半句 |
| 没过核查 | 不进正文，放第六节 |

同一节里口径一样的数字，在节首交代一次即可，不必每句重复。

## 引用

- 编号紧跟被支撑的句子：`……拿走 89% 的收入 [1]`。
- 一句最多两个编号；需要更多说明这句话太重，拆开。
- 常识性背景（公司成立年份这类）若全文只用一次且不影响判断，可以不引。

## 格式

- 二级标题用模板里的固定名字；三级标题本身是一句结论。
- 加粗只用在每条结论的短标题上，正文段落里不加粗。
- 表格格子写短语，不写句子。
- 不写"本报告""笔者"。
