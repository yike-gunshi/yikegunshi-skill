# 报告文风

摘自用户的《非结构化知识整理 SOP》，调研报告沿用。核心：**信息整理不是讲故事**。

## 要点写法

- 每条要点是「论断 + 证据」，25—70 字，必带数字 / 例子 / 条件 / 机制 / 对比之一。"用户留存不错"不合格；"30 日留存约为同类两倍，差距主要来自记忆功能【中】[3]"合格。
- 数字写在它支撑的结论旁，不搬到文末附录。
- 把一条机制拆成三条 18 字短断言等于什么也没说；宁可一条写满 70 字。
- 加粗每节 1—3 处，只标结论关键短语，不标整句。
- 不用"值得注意的是""综上所述""随着…的发展"之类过渡语和意义阐释；钩子由事实和数据承载。

## 结构

- 两级标题：节（≤12 字）与小节（≤16 字短结论）。
- 结论先行：每节第一条就是该节最重要的结论。
- 表格用于对比、框架、数字；说明段 100—250 字用于机制；列表用于并列结论。
- 来源编号紧跟被支撑的句子：`…付费率不足 5%【中】[3][7]`。置信度标签在编号前。

## 口径声明

元信息头写清时间、地域、语言口径；正文数字口径与元信息头不同时就地注明（"2025 年全球口径"）。

## 不写的

- 不写"本报告""笔者认为"。
- 不写没有来源编号的数字。
- 不在结论里用"约""大概""据说"替代缺失数据；缺就进存疑 / 待查。
- 不复述确认单内容到正文（元信息头已有）。
