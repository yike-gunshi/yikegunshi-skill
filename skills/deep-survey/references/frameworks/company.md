# 公司类调研框架

适用：对一家公司做公开信息层面的了解（合作、入职、投资、竞争分析前的摸底）。工商、司法、税务等库内信息本 skill 查不到，一律进存疑并提示需启信慧眼类接口。

## 维度

| 维度 | 关键问题 | 典型来源 | 预期查不到 / 封顶"中" |
|---|---|---|---|
| 1 基本面 | 成立时间、总部、规模（人数区间）、股权与母公司关系 | 官网、融资稿、招聘页、企查查 / 天眼查公开页 | 精确人数、股权穿透 |
| 2 产品与业务线 | 主营是什么、各业务线地位、近 12 个月上新与下线 | 官网、发布会、更新日志、媒体报道 | 各业务线收入占比 |
| 3 商业化与财务 | 收入规模线索、增速、是否盈利、主要客户类型 | 财报 / 招股书（上市）、融资稿、创始人访谈 | **非上市公司收入：封顶中** |
| 4 团队与融资 | 创始人与核心高管背景、融资轮次金额投资方、关键人员变动 | 融资新闻、LinkedIn、官方公告 | 未公开轮次与估值 |
| 5 竞争位置 | 主要对手是谁、相对优劣、客户为何选它 | 对比评测、客户案例、社区讨论 | 真实赢单率 |
| 6 风险与舆情 | 负面新闻、诉讼与处罚（公开报道层面）、裁员 / 高管离职、用户投诉 | 权威媒体、监管公告、社区 | 司法 / 行政处罚全量（需企业数据库） |

## 默认问题集

1. 这家公司是谁、靠什么赚钱、现在处境如何？
2. 它的团队和资本背景可靠吗？
3. 对我们意味着什么：能不能合作 / 入职 / 投资 / 当对手？

## 对比矩阵

单公司退化为维度事实表；多公司（如同赛道三家）按六维做矩阵。

## 本类典型「存疑 / 待查」

工商存续与变更、行政处罚、失信记录、未公开融资、精确人数。写明"需启信慧眼 / 企查查 API 等企业数据接口"。
