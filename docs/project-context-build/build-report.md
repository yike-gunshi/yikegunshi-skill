# project-context 构建与验收记录

目标：在任意项目内手动建立、更新一份完整上下文底稿，保留约定范围内的材料全文和详细说明，附加本次讨论目的后交给 ChatGPT 网页版。原始 AI 会话不在范围内。

## S0–S2：范围与设计

已确认的需求及完备性门禁见 [设计记录](s0-s2-design.md)。实现采用 Skill 编排与标准库脚本：宿主 Agent 做范围判断、实际解释与资料核验；脚本承担全文快照、增量状态、证据绑定和导出，不以标题、路径或模型摘要代替原文。

## S3：实现

- [Skill 入口](../../skills/project-context/SKILL.md)：手动触发、首次登记、全文采集、逐模块说明、导出、后续更新与中断恢复。
- [快照与导出脚本](../../skills/project-context/scripts/context.py)：`init / scan / ingest / note / build / status`；项目隔离、内容指纹、解释失效、版本保留、附件与无损分卷。
- [来源采集器](../../skills/project-context/scripts/collect_source.py)：固定只读命令的 GitHub 适配、显式飞书文档采集、已约定范围的 HTTPS JSON 生产接口；其他工具导入统一 envelope。
- 三份按需参考文档、来源/快照/说明/议题模板和 Codex 显示配置。运行要求 Python 3.10+；状态锁目前使用 macOS/Linux 的 `fcntl`。

外部来源需在各项目登记。生产资料沿用选择 B：首次明确环境、字段、窗口规则、查询方法、预算和只读机制，后续按配置手动刷新。通用 Skill 的安装不会自动连接任何生产系统。

## 使用方式

```text
$project-context 为当前项目建立完整上下文底稿，登记关联的飞书、Issue、部署与生产资料。

$project-context 更新当前项目底稿。这次想讨论新增多人协作，附上目的、背景和诉求，保留完整底稿。

$project-context 更新底稿，这次没有具体讨论议题。
```

默认状态位于目标项目的 `.project-context/`，导出在其中的版本目录。通常上传 `project-context.md`；过长时提供全部分卷及附件。详细说明由实际运行 Skill 的 Agent 依据材料撰写；Python 本身不会自动理解项目。

## S4：评测方法与边界

评测资产位于 [evals](evals/)。真实模型运行使用桌面附带 Codex 0.153.4，沿用 CLI 默认模型，没有对分组设置不同模型；执行记录没有返回可靠的具体模型标识，因此不猜测型号。

1. 确定性回归验证全文尾部、增量失效、失败保留、删除与重命名、附件、分页、范围、脱敏和持久化。采集器全部使用 mock，不访问真实业务系统。
2. 入口探测含 20 条查询，每条 3 次，训练/保留测试按 60%/40% 分组，正常读取与搜索工具、相邻 Skills 均可用。探测前言要求作出工作流选择并实际读取 Skill，故只能称“入口选择与加载探测”，不能外推自然任务触发率。
3. 实际行为对照在独立的同源合成项目中运行“有 Skill / 无此 Skill”两组，各包含首次构建和一次真实源文件变更后的增量更新。两组使用相同提示、工具与离线外部资料。无此 Skill 组仍保留正常环境中的相邻 Skills。
4. 原文以完整正文包含和不可变源文件 SHA-256 校验评分；详细解释由独立评审依据原始材料核对。用户标签确认、10% 人工抽检、真实项目源接入和 ChatGPT 网页版实际接收测试未执行。

原始事件、输出和每次用量保存在本地 `evals/model-*`；体积较大的原始轨迹不加入版本库，汇总与必要证据另存 `results/`。结果中的累计输入 tokens 包括多步上下文重读，缓存输入是其中子集，不能直接等同账单费用。

### 已取得的结果

最终快照与采集器回归 **48/48 通过**（核心 32、模拟采集 16）；主代理最后复跑 11.487 秒。Skill 体检 0 错误、0 警告。来源协议、生产接入只验证了合成数据和模拟响应，没有实接业务系统。

入口选择与实际加载 **60/60 符合作者拟定标签**：训练 36/36、保留测试 24/24；30 次正例加载、30 次近似负例未误入。沿用同一 description，中位耗时 12.279 秒。标签未经过用户确认，所以不把这一数字说成真实任务成功率。

| 对照阶段 | 原文与清单（30 分） | 用 Skill 耗时 | 无此 Skill 耗时 | 用 Skill 累计 tokens | 无此 Skill 累计 tokens |
|---|---:|---:|---:|---:|---:|
| 首次生成 | 两组 30/30，全文 13/13 | 196.1 秒 | 202.7 秒 | 391,661 | 187,742 |
| 实际变更后更新 | 两组 30/30，当前/保留全文 12/12 | 204.4 秒 | 177.4 秒 | 522,661 | 277,095 |

累计 tokens 为工具返回的输入加输出，包含多步重读；缓存输入已包括其中。Skill 组有更多状态和脚本读取，本例累计量更高，不能宣称节省额度。两组都保留了完整材料并识别文档 24 小时、当前代码 48 小时、部署版本未变的冲突。这个小样本在全文和清单上**没有表现出相对增益**；这两项保留为必要正确性门槛，不再作为质量提升卖点。

Skill 组额外使用统一的指纹说明、失败状态和上一完整版本指针；这些可维护机制经过独立脚本回归验证。行为对照对应 [记录的冻结版本](results/evaluated-versions.json)；后续范围/删除/脱敏修复由最终 48 项回归验证，不能把冻结产物冒充新版重跑。

匿名文档评审使用三份独立评分。两位评审此前参与过实现审查，文档本身也可能暴露工具信息，故不称严格双盲。审查包路径被匿名化，导致文档哈希与原清单不同；恢复原路径后吻合，原产物保持不变。

评审发现：两组增量产物都把由静态导入关系可预测的失败写为“已执行测试失败”。原始执行轨迹及生成脚本未提供该次测试执行证据；该过程声明不能成立，不能用结果可预测来代替实测。已在新版解释规则中区分旧报告、本轮实测与静态推断，并单独验证；旧评分不回填为通过。

新版定向模型运行已完成，81.886 秒。输出明确写“本轮没有实际执行验证”，将旧导入路径写为静态风险，并把部署记录的声明与现场核验分开；见 [实际输出](results/verification-note-v2.md)。这是一次明确要求不运行代码/测试的定向检查，不能证明所有未来任务都不会出现同类错误。

三份文档评审按每项中位数汇总：初次两组均 60/60；增量用 Skill 为 50/60，无此 Skill 为 48/60。两组增量的“诚实交付”都因无实测证据而记零分，其余材料/解释分不为同一问题重复扣分。2 分差距不足以宣称广泛质量提升。两组配对检查均确认旧议题移除、真实计划保留、外部旧正文标旧以及重命名/删除说明。评分原件与各项样本见 [完整结果](results/summary.json)。

## S5：发现、归因与修正

| 发现 | 归因与处理 |
|---|---|
| 第一批隔离入口探测未展示目标 Skill | 评测安装位置错误；移入合成项目 Git 根目录并作目录可见性预检。该批标为无效，不计入效果指标，未为它修改 description。 |
| 首次客观评分把两组清单都判为零 | 评分器只接受未在任务中约定的字段名；支持语义等价的机器清单，并核对原文指纹。未改模型产物。 |
| 分页仍有顶层游标却声称完成 | 收录逻辑缺陷；检查游标并降为部分完成。 |
| 业务 `history.jsonl` 被当作 AI 会话排除 | 过宽规则；改用明确文件名/结构，不以泛化的 history 名称判聊天。 |
| Git 原始 diff 可能把已排除会话重新带入 | 去掉原始补丁，保存工作区状态和变更数量；当前实际源码仍全文保留。 |
| 本地文件或目录临时不可读被当删除 | 保留上次正文并记录本轮读取失败，完整版本指针保持不变。 |
| 飞书无 revision 时生成无法导入的完整快照 | 使用明确标注的内容 SHA-256 版本；不冒充提供方版本。 |
| 恢复缓存只显示新的封装时间 | 记录每个缓存响应的实际抓取时间及最早/最晚时间，累计预算跨恢复保留。 |
| 公共文档定位符在序列化后被重复脱敏 | 统一精确引用名识别，真实凭证继续掩码，保留可追溯定位信息。 |
| 相同正文导致旧运行区间说明仍有效 | 运行说明额外绑定配置和来源证据状态。 |
| 部分增量的暂缓删除在末页丢失 | 保存待定删除，完成增量后应用，重新出现或完整权威快照可消解。 |
| 两组增量文档将静态测试错误写成实测 | 行为与说明规则缺口；补充通用证据来源区分，保留原失败样本，另做新版定向检查，不宣称原对照已通过。 |

删减动作：采集器删除重复的手写原子 JSON 保存实现，复用核心持久化；Skill 主文删除已经由采集步骤与参考文档覆盖的重复时间一致性说明。description 保持冻结，未依据保留测试集调参。

后续最有价值的三个方向：在一个真实项目校准外部来源范围；用大规模真实代码库检验解释质量与更新成本；由用户抽检并在网页版验证交接后的功能设计回答。这些均未冒充本轮已完成。
